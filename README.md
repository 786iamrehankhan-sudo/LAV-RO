# LAVÉRO

LAVÉRO — a modern fragrance house where scent, design and memory become one immersive experience.

## About

**LAVÉRO — The Art of Wearing a Moment**

An immersive 3D fragrance showroom built with modern web technologies.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
